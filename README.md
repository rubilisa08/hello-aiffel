1. **감성 분석 챗봇** — 사용자의 텍스트 입력에서 감정을 분석하고 공감하는 답변을 생성하는 챗봇

3. **이미지 캡셔닝 모델** — 사진을 입력하면 자연스러운 한국어 설명을 생성하는 모델
